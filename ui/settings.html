状态说明 / 卡住了怎么办
  • 正在跑：执行中，页面自动刷新，无需操作。
  • 已完成：本批跑完，待复核（不等于盈利结论）。
  • 需处理：登录 / 权限 / 浏览器控制权问题，处理后点「继续 / 核对」。
  • 需核对 / 不确定：有副作用残留（如加车结果不确定），人工核对后再决定，勿盲目重发。
  • 受阻：中途失败，按错误码建议处理。
  • 已超期：超过 30 分钟期限，只能只读对账。

1优先方向

让系统更偏向「应季」和「近期起量」的商品；两个方向可同时开启。不勾选 = 不做优先，不影响其他规则。

3可选业务条件

硬门槛：数字留空 = 不限；填写 0 = 明确按 0 计算。不满足任一已填条件，商品不会入选。

价格

例：只做 10–50 元的品 → 最低 10、最高 50、口径选「到手价」。

佣金

例：填 20 = 佣金率不低于 20%；填 5 = 每单佣金不低于 5 元。

销量

例：填 100 = 至少卖出 100（按所选周期）。

转化

新手建议留空：口径组合较多，容易误杀好商品。

4缺数据与运行预算

每批任务的硬边界，防止无限翻页、持续加车；推荐保持：入车 3、广场 3 页、候选 60。

推荐「进入决策页补查」：更准，但每单多花一点时间。

建议 3：系统单批最多 3 个，达到就停。

建议 3：翻页越多越慢。

建议 60：进入候选排序池的商品数。

5视频归档

把选中商品的视频存到哪台机器：填服务端 Mac 或其已挂载 NAS 的绝对目录路径，不是手机 / Windows 客户端的磁盘。可手填；「选择文件夹」窗口在服务端 Mac 打开，需在那里完成选择。

保存仅记录地址，不创建目录、不搬动已有视频。任务开始前再核验目录和写入权限。
