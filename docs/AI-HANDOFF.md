# AI 接手约定

## 先读

README → STATUS → SECURITY → ARCHITECTURE → DEPLOY。

这是源码/测试备份，不是软件修复或业务执行授权。生产基线为 Wave19/UIv8，整体 BLOCKED；独立 W20 fix3 分支未完成、未部署、不可发布。

## 第一次接手

1. 检查分支、Git 状态和已审 manifest；确认没有把候选覆盖 main。
2. 确认 Node 环境，执行 README 的离线检查，记录真实退出码。
3. 阅读测试前提；缺媒体或专用 harness 不是修复通过，也不能用合成通过输出替代。
4. 若发现新敏感字段、签名 URL、私人路径或真实商品/账户，停在本地审核门，禁止上传 blob。

## 不能做

- 不读取用户 .env、gh 凭据文件、Cookie、浏览器 History 或生产数据库来“补齐配置”。
- 不默认执行加车、下载、飞书写入、NAS 访问、真实浏览器或生产任务恢复。
- 不导入生产 .git 历史，不运行旧批动作，不重启服务。
- 不将局部候选测试结果当作独立父验收，不自动合并或部署 W20。
- 不依赖 .gitignore 作为唯一隐私证明；暂存 blob 必须逐文件对照 manifest。
- visibility、协作者、其他仓库或全局 Git 设置须父明确授权后才能变更。

何时必须停下：发布权限未给、验收仍 BLOCKED、外部动作范围不明、凭据缺失或敏感审计存疑。父独立审核之后的新明确授权才允许向同一个仓库发布（当前为公开仓库）。
